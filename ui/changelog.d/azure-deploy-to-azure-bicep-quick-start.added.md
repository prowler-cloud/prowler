Add a Deploy to Azure quick-start to the add-provider wizard. Azure now shows a credential-type selector (Certificate authentication recommended, Service Principal with Client Secret fallback). The certificate form guides the user through creating the App Registration and uploading the certificate in the Portal (with an in-browser "Generate certificate for me" helper that keeps the private key client-side), then a one-click Deploy to Azure button that opens the Portal deployment blade pre-loaded with the Prowler Bicep template to assign the built-in Reader role and a custom ProwlerRole to that App Registration's service principal
