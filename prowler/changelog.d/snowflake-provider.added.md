Snowflake is now a supported provider. It authenticates with an RSA key pair against a `TYPE = SERVICE` user and reads Snowflake's own `ACCOUNT_USAGE` views over the SQL API, so it adds no new dependency. The first check, `users_mfa_enabled`, reports users who can sign in with a password but are not protected by MFA — counting both native MFA and the legacy Duo integration, and treating an open `BYPASS_MFA_UNTIL` window as unprotected.
