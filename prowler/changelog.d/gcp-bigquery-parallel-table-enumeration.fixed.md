The GCP BigQuery service now describes datasets and tables through a bounded thread pool instead of one serial round trip per resource, so scanning a project with a large BigQuery estate no longer appears to hang for the duration of the enumeration. Each worker holds its own `AuthorizedHttp`, since `googleapiclient`'s http object is not thread safe, and a table that cannot be read is skipped and logged rather than abandoning the rest of its dataset.
